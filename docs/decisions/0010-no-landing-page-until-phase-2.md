# 0010 — No landing page until Phase 2

- Status: accepted · 2026-11-23
- Context: The site covers one corridor (Kota Kemuning ↔ PJ). The PRD's main user, the curious commuter, should understand the map in ten seconds. A landing page would put a click between them and the answer, and with one corridor there is nothing to choose on it.
- Decision: One page — map plus panel — that leads with the finding (headline, confirmed jam spots, top fix) and keeps caveats in "How this works". No separate landing page.
- Consequences: When Phase 2 adds several corridors, a "pick your commute" page goes in front and this page becomes the per-corridor template. Shareability (deep links per finding, preview image) is handled on this page, not by a landing page.
